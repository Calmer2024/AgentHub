> 本文档汇总 AgentHub 的作品链接、交付文档、Demo 说明和仓库材料索引。产品设计、技术设计、AI 协作记录、Demo 视频、代码仓库和可运行包均从本入口进入。

## 1. 项目简介

AgentHub 是一个以 IM 聊天为核心交互范式的多 Agent 协作平台。用户可以像使用飞书或微信一样创建项目、进入单聊或群聊，与 Claude Code、Codex、OpenCode 等真实 CLI Agent 协作完成代码、网页、文档等产物。

平台围绕“一个任务从需求到产物”的完整链路设计：用户提出目标，Orchestrator 在群聊中拆解任务并分派 Agent，Agent 在项目 workspace 中执行，产物以消息级 Artifact 卡片、预览、编辑、版本和部署形态回到聊天流中。

## 5. Demo 内容

### 主线一：桌面端本机稳定闭环

1. 双击启动 AgentHub Local Desktop。
2. 创建 Project，绑定本机 workspace。
3. 创建单聊，请 Agent 读取或修改项目文件。
4. 查看 Agent 输出、执行过程、文件变更和 Artifact 卡片。
5. 创建群聊，让 Orchestrator 拆解一个网页或后端任务。
6. 查看多个 Agent 的阶段性输出、计划执行和结果汇总。

### 主线二：SaaS 云端能力

1. 展示 SaaS Web 入口。
2. 展示团队、云端 workspace、仓库导入、快照恢复。
3. 展示云端 Agent Runtime、云端产物预览和一键部署访问链接。

### 主线三：AI 协作开发过程

1. 展示 `CLAUDE.md` / `CONTEXT.md` 规则。
2. 展示 `docs/archive/phases/specs/` 阶段规格。
3. 展示早期 Skill 在 Git 历史中的演进和退役记录。
4. 展示 `docs/archive/phases/dev-logs/` 阶段开发记录。
5. 说明项目不是简单“用 AI 写代码”，而是建立了可复用的人机协作开发体系。

## 7. 可运行 Demo 说明

### 桌面端

桌面端会启动本地 AgentHub 后端，并在桌面 WebView 中打开前端界面。

```text
双击 AgentHub Local Desktop.exe
```

### 开发模式

从源码启动：

```powershell
cd backend
.\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8188 --reload

cd frontend
npm install
npm run dev
```

浏览器打开前端地址，默认使用 `http://127.0.0.1:5173`。
